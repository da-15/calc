# 式電卓

式と履歴が見えて、過去の答えを参照できる電卓のPWAです。

**公開ページ**：https://da-15.github.io/calc/

## できること

- 四則演算と括弧の計算。入力中の式と途中の答えを同じ行に表示
- `%`（200+10% → 220）、`±`、`00`、`000`
- 履歴は最大200件まで端末に保存
- 履歴の答えをタップすると式に参照として入る。参照元の行を編集すると、参照している行も再計算
- 履歴の行を長押しすると「式をコピー」「答えをコピー」のボタンが出る（カンマなし）
- 履歴の行をタップして編集・削除
- テンキーを下にスワイプして隠し、上にスワイプして戻す
- 入力欄が空のときに AC で履歴をすべて消去（確認あり）

## ホーム画面に追加する

- **iPhone**：Safariで開き、共有ボタン →「ホーム画面に追加」
- **Android**：Chromeで開き、メニュー →「アプリをインストール」

一度開けば、オフラインでも起動できます。

## ファイル構成

`docs/` を GitHub Pages で公開しています。

| ファイル | 内容 |
| --- | --- |
| `docs/index.html` | 電卓本体 |
| `docs/manifest.webmanifest` | アプリ名・アイコンなどの設定 |
| `docs/sw.js` | オフライン用のキャッシュ |
| `docs/icons/` | ホーム画面用アイコン |

`docs/` のファイルを更新したときは、`docs/sw.js` の `CACHE` の番号（`calc-v6` など）を上げてください。次に起動したときに新しい版に入れ替わります。アイコンを差し替えたときは、`docs/index.html` と `docs/manifest.webmanifest` にあるアイコンのURLの `?v=` の番号も上げてください。
