# 式電卓

式と履歴が見えて、過去の答えを参照できる電卓のPWAです。

**公開ページ**：https://da-15.github.io/calc/

## できること

- 四則演算と括弧の計算。入力中の式と途中の答えを同じ行に表示
- `%`（200+10% → 220）、`±`、`00`
- `±` は、選んだ数字や、カーソルの直前のまとまり（数字・参照・括弧で囲んだ部分）の符号を切り替える（12×5 → 12×(−5)、12×(3+5) → 12×(−(3+5))）
- 履歴は最大200件まで端末に保存
- 履歴の答えをタップすると式に参照として入る。参照元の行を編集すると、参照している行も再計算
- 履歴の行を長押しすると「式をコピー」「答えをコピー」のボタンが出る。コピーする文字は、カンマなし・記号はキーボードで打てるもの（`(-15)*2+1000`）
- 入力欄を長押しすると「貼り付け」のボタンが出る（カンマや全角は自動で整え、式の途中なら括弧で囲む）
- パソコンでは Ctrl+V（Macは⌘+V）で貼り付け、Ctrl+C（⌘+C）で入力中の「式=答え」（数字を選んでいればその数字）をコピー
- 履歴の行をタップして編集・削除
- 入力欄の数字や記号をタップして選ぶ。数字は数字キーで、演算子は演算子キーで置き換わり、⌫で消える。それ以外のキーは選んだものの直後に入る。もう一度タップすると、その直後にカーソル
- テンキーを下にスワイプして隠し、上にスワイプして戻す
- 履歴や入力欄をピンチすると、文字の大きさが変わる（14〜32px。パソコンは Ctrl+ホイールやトラックパッドのピンチ）
- 入力欄が空のときに AC で履歴をすべて消去（確認あり）

## ホーム画面に追加する

- **iPhone**：Safariで開き、共有ボタン →「ホーム画面に追加」
- **Android**：Chromeで開き、メニュー →「アプリをインストール」

一度開けば、オフラインでも起動できます。

## ファイル構成

`docs/` を GitHub Pages で公開しています。`docs/` の外にあるファイルは公開されません。

| ファイル | 内容 |
| --- | --- |
| `docs/index.html` | 画面の骨組み（HTML） |
| `docs/style.css` | 見た目 |
| `docs/calc.js` | 計算の仕組みと入力ルール。画面には触らない関数だけ |
| `docs/app.js` | 画面の操作（履歴・編集・コピーと貼り付け・テンキーの出し入れ・ピンチなど）。先頭の `CONFIG` に調整用の数値をまとめている |
| `docs/manifest.webmanifest` | アプリ名・アイコンなどの設定 |
| `docs/sw.js` | オフライン用のキャッシュ |
| `docs/icons/` | ホーム画面用アイコン |
| `tests/calc.test.js` | 計算と入力ルールのテスト（ブラウザ不要） |
| `tests/ui.test.js` | 画面の操作のテスト（Chromium でタップやキー入力を再現） |

### どこを直せばいいか

- 計算の結果や、キーを押したときの式の変わり方 → `docs/calc.js`
- 長押しの時間、文字の大きさの範囲、履歴の件数など → `docs/app.js` の `CONFIG`
- 色・文字・余白などの見た目 → `docs/style.css`（色は先頭の `:root` にまとめている）
- ボタンの並びや文言 → `docs/index.html`

## テスト

初回だけ準備します（Node.js 22 以降）。

```sh
npm install
npx playwright install chromium
```

すべてのテストを流します。計算と画面の操作、あわせて20項目あまりを1分ほどで確かめます。

```sh
npm test
```

計算だけを確かめるなら、ブラウザなしで数秒で終わります。

```sh
npm run test:calc
```

手元のブラウザで動きを見たいときは `npm run serve` を実行し、http://localhost:8080 を開きます。

## 更新するときの手順

1. `docs/` のファイルを直す
2. `npm test` で、すべてのテストが通ることを確かめる。新しい動きを足したら、テストも足す
3. `docs/sw.js` の `CACHE` の番号（`calc-v29` など）を1つ上げる。上げないと、すでに使っている端末に新しい版が届かない
4. `docs/` にファイルを増やしたときは、`docs/sw.js` の `FILES` にも足す
5. アイコンを差し替えたときは、`docs/index.html` と `docs/manifest.webmanifest` にあるアイコンのURLの `?v=` の番号も上げる（端末が古い画像を覚えているため）
6. `main` に push すると、数分で公開ページに反映される。端末ではアプリを一度閉じて開き直すと新しい版になる

### iPhone で気をつけること

- 指が触れた瞬間（`pointerdown` や `touchstart`）に画面の表示を変えると、iPhoneはそのタップを取り消すことがある。表示の変化はタップが確定したあと（`click`）に起こす
- クリップボードの読み書きは、タップの処理の中でしかできない。長押しではボタンを出し、ボタンのタップでコピー・貼り付けする
- iPhoneでの細かい動き（画面全体の拡大、ペーストの確認の吹き出しなど）はテストでは再現できないので、実機でも確かめる
